# Manter README

1. Ler integralmente [references/workflow.md](references/workflow.md) antes de editar o README.
2. Ler as instruções do repositório e inspecionar os arquivos que comprovam cada informação relevante.
3. Antes de alterar arquivos versionados, confirmar o Git Flow `feature/<descricao-curta> → develop → main` definido no `AGENTS.md`.
4. Tratar o repositório como fonte da verdade e não inventar comandos, funcionalidades ou decisões.
5. Fazer a menor atualização que deixe o README claro, navegável e coerente com o estado atual.
6. Validar links, comandos e referências sempre que possível.
7. Resumir as seções alteradas e as evidências usadas.
